### **REST API для работы с сущностями**

Entity Manager это REST API приложение для управления сущностями (например, задачами) с поддержкой CRUD операций, фильтрации и изменения статусов. 
В дальнейшем возможно расширение функционала в зависимости от назначения сущности.

#### Запуск проекта:
1. docker build -t entity-manager-app:latest .
2. docker-compose up -d

* Приложение доступно по http://localhost:8080
* Swagger UI: http://localhost:8080/swagger-ui.html
* PGAdmin: http://localhost:5050 (admin@admin.com/admin)
* Документация: http://localhost:8080/swagger-ui.html

#### Основные возможности:

1. CRUD: создание, чтение, обновление и удаление сущностей
2. Управление статусами: PENDING → IN_PROGRESS → COMPLETED/FAILED с валидацией переходов
3. Фильтрация и поиск: по статусу, приоритету, дедлайну, названию и комбинированная фильтрация
4. Автоматическая обработка дедлайнов — сущности автоматически переводятся в статус FAILED после истечения срока выполнения, если не завершены
5. Валидация данных: проверка входных данных
6. Документация в Swagger UI
7. Развертывание через Docker
8. CI/CD для модульных тестов к CRUD операциям

#### Используемые технологии:

1. Backend: Java 21, Spring Boot 3.2.4
2. Тестирование: JUnit 5.10.0, Mockito 5.7.0
3. База данных: PostgreSQL
4. ORM: Hibernate
5. Документация API: Springdoc OpenAPI (Swagger UI)
6. Сборка и управление зависимостями: Maven
7. Контейнеризация: Docker, Docker Compose
8. Инструменты: Lombok, Flyway
